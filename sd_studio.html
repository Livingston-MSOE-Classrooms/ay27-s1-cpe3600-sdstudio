Put SDWriter.bin on the board

  1. Card in the shield's socket, shield on the board, USB cable in.
  2. Drag SDWriter.bin (next to this page) onto the NOD_G474RE drive. The drive disappears and comes back while the board reprograms itself.
  3. The screen goes black with a gray bar at the bottom; the square at its right is green if the card mounted.
  4. Click Connect to the board at the top and pick the STLink virtual COM port. Close any serial terminal that has it open first.

When you're done, flash your own project back on from CubeIDE. Have a card reader? You don't need the board at all: save the files from the Images or Fonts tab and drag them onto the card.

Text on the board's screen

The files

.565 images. Bytes 0–3 are R565, bytes 4–5 the width and 6–7 the height (both little-endian, like the Cortex-M4), then width × height pixels, two bytes each, high byte first, row by row from the top left. That pixel order is what the ILI9341 wants after RAMWR, so a row can go from the card to the display untouched: set the window to the image's rectangle, then send the bytes. A file with no header that's exactly 130,560 bytes is a 240 × 272 Lab 6 image.

typedef struct {
    char     magic[4];   // 'R' '5' '6' '5'
    uint16_t width;      // pixels
    uint16_t height;
} r565_header_t;         // 8 bytes, then width * height * 2 bytes of pixels

Fonts. FONTS/SANS16B/ holds 020.565 (space) to 07E.565 (~), one R565 image per character, all the same height. Draw a string by opening each character's file and drawing it where the last one ended; the image width is the advance. FONT.TXT lists the height, baseline, colors and character range as key=value lines.

Names. The card uses 8.3 names: up to 8 letters, digits, _ or -, a dot and up to 3 more. The page makes every name fit.

Getting files onto the card

With a card reader: Download .zip (unzip it, then drag the folders onto the card) or Save to a folder… (pick the card's drive itself and the page writes straight to it, folders and all). Without one: put SDWriter.bin on the board (Card tab) and use Write to the card.
